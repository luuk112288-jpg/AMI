# Asset and dependency provenance

- Music: eight original deterministic electronic/ambient demo compositions generated by `scripts/generate-audio.mjs` for AMI. No external samples, commercial recordings, or Spotify audio are used. Titles and artist identities are fictional demonstration content.
- Artwork: original procedural Canvas demo artwork in `ui/components/Artwork.kt`. The new AMI launcher/logo image at `res/drawable-nodpi/ami_logo.png` was generated for this project with OpenAI image generation. The original vector icon is retained as an unused historical asset.
- Local album covers and metadata are read from the user's audio files on-device. No online artwork lookup is performed.
- Test fixture audio is an FFmpeg-generated sine tone with synthetic tags and the AMI logo as embedded cover; it is included only in the instrumentation test APK.
- Icons: AndroidX Material Icons, distributed with the AndroidX dependency under Apache License 2.0.
- AndroidX libraries (Compose, Media3, Room, DataStore, Navigation, lifecycle): Apache License 2.0. Kotlin: Apache License 2.0. Gradle: Apache License 2.0. See upstream artifacts for full dependency notices.
- REA: https://github.com/morluto/rea, MIT. Consulted as the requested analysis-tool source. No upstream REA code or binary is bundled in this application. No completed REA capture is claimed.
- Spotify is referenced only to describe the requested application category. AMI is independent and has no Spotify affiliation or bundled Spotify catalog.

The supplied original source and generated demonstration assets are available for the user's AMI project. Third-party components retain their respective licenses.

- Audius integration: catalog metadata, artwork and streams are requested at runtime through the public Audius API. Audio/artwork is not bundled in the APK. Artist names and Audius source links are retained; playback uses the stable API stream endpoint rather than storing temporary signed content-node links.
- OkHttp 4.12.0: Apache License 2.0. MockWebServer and org.json are JVM test dependencies only.
